# Air Quality Tracker

This is a simple web application that fetches real-time air quality data using the OpenAQ API.

## Features
- Enter a city name to get air quality readings.
- Displays multiple pollutant levels in an easy-to-read format.

## How to Use
1. Open `index.html` in a browser.
2. Enter a city name (e.g., Los Angeles) and click "Check Air Quality".
3. The page will display air quality data if available.

## Deployment on GitHub Pages
1. Upload all files to a GitHub repository.
2. Go to **Settings > Pages** and enable GitHub Pages using the **main branch**.
3. Access the website via `https://yourusername.github.io/repository-name/`.
