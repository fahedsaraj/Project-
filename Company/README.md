# United International Academy: Marketing Department Workspace

*Shaping Global Minds.* This folder is the operating system of the UIA marketing department: one human leader (Fahed) plus a connected AI team that plans, produces, measures and improves. Project instructions are in `/CLAUDE.md`.

## Map
| Folder | What lives here |
|---|---|
| `00_Context/` | Who Fahed is, voice, working preferences, priorities, open decisions, memory |
| `00_Blueprint/` | Strategy, team operating model, transition strategy, role files (`Team/`) |
| `00_Activity_Logs/` | One log per agent, plus `combined_activity_log.pdf` |
| `01_Tools/` | Scripts the team builds: logo asset builder, combined-log PDF builder |
| `02_Reference/` | Research and reference: social/ads audit, brand summary, Fahed's answers verbatim |
| `03_Assets/` | Brand guidelines, official logo library, email signature |
| `04_Projects/` | Active projects. **P01 Foundation & Transition** is live |
| `05_Operations/` | Ownership & access, phone number standard, email setup (legal, finance, ops) |
| `06_Outreach/` | Client, school and partner outreach (parked until P01 Phase 3) |
| `07_Briefs/` | Daily morning briefs |
| `08_Reviews/` | Weekly reviews and 30/60/90-day checkpoints |
